# Python Pro Bootcamp Portfolio

This repository tracks my hands-on journey through Angela Yu's Python bootcamp. Instead of storing every basic syntax exercise, I chose to curate and showcase some standout projects and capstones ranging from terminal utilities and arcade games to web scraping and external API integrations.

---

## 📂 Project Structure

The portfolio is organized into progressive difficulty levels:

- **`01-beginner-fundamentals/`** — Command-line utilities and core logic.
- **`02-intermediate-oop-games/`** — Arcade games built with Object-Oriented Programming.
- **`03-advanced-apis-and-data/`** — Projects powered by external APIs and data tools.
- **`04-web-scraping-and-bots/`** — Web scraping scripts and browser automation bots.

---

## 🛠️ Tech Stack & Skills

* **Languages:** Python 3
* **Core Concepts:** Object-Oriented Programming (OOP), Data Structures, Algorithms, Error Handling
* **Libraries & Tools:** Pandas, Requests, BeautifulSoup, Selenium, Tkinter, Git & GitHub
