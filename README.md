# Python Pro Bootcamp Portfolio

## Português

Este repositório documenta a minha jornada prática no Python Pro Bootcamp da Angela Yu. Em vez de guardar cada exercício básico de sintaxe, decidi selecionar e destacar os melhores projetos e capstones, variando desde utilitários de terminal e jogos de arcade até web scraping e integrações com APIs externas.

---

## English

This repository tracks my hands-on journey through Angela Yu's Python bootcamp. Instead of storing every basic syntax exercise, I chose to curate and showcase some standout projects and capstones ranging from terminal utilities and arcade games to web scraping and external API integrations.

---

## 📂 Project Structure / Estrutura do Projeto

- **`01-beginner-fundamentals/`** — Utilitários de terminal e lógica essencial / Command-line utilities and core logic.
- **`02-intermediate-oop-games/`** — Jogos de arcade construídos com Programação Orientada a Objetos / Arcade games built with OOP.
- **`03-advanced-apis-and-data/`** — Projetos alimentados por APIs externas e ferramentas de dados / Projects powered by external APIs and data tools.
- **`04-web-scraping-and-bots/`** — Scripts de web scraping e bots de automação de navegador / Web scraping scripts and browser automation bots.

- **Core Concepts / Conceitos:** Object-Oriented Programming (OOP), Data Structures, Algorithms, Error Handling
- **Libraries & Tools / Bibliotecas:** Pandas, Requests, BeautifulSoup, Selenium, Tkinter, Git & GitHub
